About the Project

This is an Excel dashboard project I created to analyze customer churn in a bank.
The main goal of this project was to understand how many customers have left the bank, look at different customer characteristics, and identify patterns that may be related to customer churn.
I also used this project to practice data cleaning, pivot tables, pivot charts, KPIs, and interactive Excel dashboards.

Dataset

The dataset contains customer-related information such as:
Customer ID
Surname
Credit Score
Geography
Gender
Age
Tenure
Balance
Number of Products
Credit Card Status
Active Member Status
Estimated Salary
Churn/Exited Status
What I Analyzed

Some of the things I looked at in this project include:
Total number of customers
Number of customers who churned
Churn rate
Customer distribution by geography
Churn based on gender
Churn based on age
Churn based on customer activity
Churn based on number of products
Credit score and balance patterns
Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Excel KPIs
Data Cleaning
Project Structure

The Excel workbook is organized into different sections:
Raw Data – Original dataset
Clean Data – Cleaned and organized data
Pivot Tables – Tables created for analysis
Pivot Charts – Visualizations based on the pivot tables
Dashboard – Final interactive dashboard
